# Customer Churn Prediction

A production-grade machine learning project for predicting telecom customer churn.
Built with a modular `src/` package, a CLI training pipeline, a scoring script,
and a full EDA notebook — structured the way a real ML engineering project should be.

## Quick Start

```bash

# 2. Train all models (runs full pipeline, saves artefacts + figures)

# 3. Score new customers
python predict.py --input data/telco_churn.csv --output predictions.csv
```

## CLI Reference

### `train.py`

```
python train.py [--config config.yaml] [--data PATH] [--output DIR] [--figures DIR]
```

Runs the full 9-step pipeline: load → clean → engineer features → split → scale → CV → fit → evaluate → save.

### `predict.py`

```
python predict.py --input PATH [--output PATH] [--model MODEL] [--threshold FLOAT]

Options:
  --model      logistic_regression | random_forest | gradient_boosting | xgboost
               (default: gradient_boosting)
  --threshold  Decision threshold for churn flag (default: 0.5)
```

Output columns: `customerID`, `churn_probability`, `churn_flag`, `risk_tier` (Low / Medium / High / Critical).

## Feature Engineering

Three domain-driven features augment the raw 21-column dataset:

| Feature | Formula | Rationale |
|---------|---------|-----------|
| `avg_monthly_spend` | `TotalCharges / (tenure + 1)` | Normalises cumulative spend by tenure |
| `is_new_customer` | `1 if tenure < 12 else 0` | Binary flag for high-risk first-year window |
| `services_count` | Sum of 6 add-on Yes flags | Each service raises switching cost |

## Model Results

Trained on 5,634 customers, evaluated on a held-out test set of 1,409 customers.

| Model | CV AUC | Test AUC | Precision | Recall | F1 | MCC |
|-------|--------|----------|-----------|--------|-----|-----|
| **Logistic Regression** | **0.7189 ± 0.0134** | **0.7289** | **0.4055** | **0.7460** | **0.5254** | **0.3099** |
| Random Forest | 0.7170 ± 0.0174 | 0.7153 | 0.3985 | 0.6979 | 0.5073 | 0.2808 |
| XGBoost | 0.7111 ± 0.0187 | 0.7059 | 0.3941 | 0.6818 | 0.4995 | 0.2686 |
| Gradient Boosting | 0.7052 ± 0.0163 | 0.7010 | 0.4355 | 0.1444 | 0.2169 | 0.1196 |

**Best model:** Logistic Regression (Test AUC = 0.7289)  
**Optimal threshold (max-F1):** 0.42 → Precision = 0.388, Recall = 0.845, F1 = 0.532

---

## Top Churn Drivers

1. **Contract type** — month-to-month customers churn at ~42% vs 3% for two-year contracts
2. **Tenure** — first-year customers are highest risk (`is_new_customer` flag)
3. **Electronic check payment** — churn rate ~45%, more than double autopay cohort
4. **Fibre optic internet** — higher spend, elevated churn
5. **Services count** — 4+ services cuts churn rate below 15%
